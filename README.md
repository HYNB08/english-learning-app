# 英语学习应用

## 项目结构
```
english-learning-app/
├── frontend/                    # 前端文件夹
│   ├── index.html              # 前端页面
│   └── README.md               # 前端说明
├── backend/                    # 后端文件夹
│   ├── package.json            # 后端依赖配置
│   ├── server.js               # 后端服务器代码
│   └── README.md               # 后端说明
└── README.md                   # 项目总说明
```

## 技术栈
- **前端**: HTML + CSS + JavaScript + Tailwind CSS
- **后端**: Node.js + Express
- **数据库**: MongoDB Atlas
- **部署**: Vercel (前端) + Railway (后端)

## 功能特性
- 用户注册/登录
- 基础界面导航
- API连接测试
- 移动端适配

## 部署说明
1. 前端部署到 Vercel
2. 后端部署到 Railway
3. 数据库使用 MongoDB Atlas
4. 修改前端API地址为Railway URL
